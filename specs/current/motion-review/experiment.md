# Motion 时间点反馈：2026-10-26 实际模型对照

没有观察到首次成功率和修改轮次的改善。模型执行耗时均值从 119.9 秒变为 114.3 秒，描述性下降 4.6%；每题仅一对样本，不能确认稳定提升。

## 方法与边界

从历史真实会话提取 3 条原始修改要求。历史文件存在缺失、脱敏损坏或旧协议兼容问题，因此全部用当前模型重建共同起点，不冒充历史原版回放。两组起始文件逐字节相同。

旧组使用完整原始文字，新组使用相同文字并增加通过真实 UI 保存的暂停时刻、目标和截图。固定执行代码 `70c01384ce`、OD Next active、AMR/Vela 0.1.7；每轮实际 resolved model 均为 `gpt-6.1-sol`。两组请求推理参数均为 `medium`，上游有效推理档位未独立记录。调用串行无重叠，椅垫任务按新→旧，其余按旧→新。

最多允许 3 轮，达到验收即停止。独立 AI 产品评审仅查看匿名候选、冻结要求、源码和真实浏览器采样，不读取组别映射。这里的首次成功指本轮验收通过，不代表用户满意度。

## 结果

| 任务 | 旧组耗时 | 新组耗时 | 首次验收（旧／新） | 用户轮次（旧／新） |
| --- | ---: | ---: | --- | --- |

首次验收两组均为 3/3，平均轮次均为 1。椅垫任务的非目标场景在 3、6.5、9 秒的两组画面，与修改前逐像素一致；两组 R 重播均实际返回开头。采样验证不扩大为整片每帧证明。

耗时取本地 API 受理至最终产物终态，包含宿主检查和安全修复，不含起点生成、人工验收等待、反馈准备和 MP4 导出。没有测量用户组织反馈的时间、满意度或模型费用。

## 发现与后续

- 默认 active 路径此前只冻结评论数量，丢失时间和目标。已在本地修复为冻结反馈 JSON 与截图哈希绑定；定向回归、构建、guard 和 typecheck 通过。三次新组执行均有实际读取该 JSON 的事件证据。
- 实际注释截图中的 SVG 样式存在失真。本轮保留实际传递的截图，没有用验收截图替换模型输入；该问题尚未修复。
- 截图传递与哈希绑定已核对，但日志没有直接证明模型消费了 PNG 像素，不能把结果归因为视觉理解改善。
- 新组两题更快、一题更慢。原始文字已详细写清对象和时序，尚不能确认附加定位信息带来稳定效果，也不能推断它没有价值。降低反馈准备成本仍需实际用户流程对照。
