# Motion 编辑工作台首版方案

日期：2026-10-26。工作分支：`codex/motion-review-20261025`，实现前 head：`9a98c84d480194c269e04ab2d1fbb52be36a0999`。

## 产品决定

将 Motion 预览底部播放器升级为可审阅的编辑工作台：**聊天继续修改同一作品，画布指出位置，时间线指出时刻，批注记录修改要求**。本轮目标是让用户看到并试用真实产品内的首版。

主参考 Motion.so，沿用 Open Design 已有画布、评论、对话和确定性播放器。对齐交互职责，不照搬未具备的数据能力。详细竞品背景见 [竞品核查](./editor-competitive-research.md)。

## 本版需求与取舍

| 编号 | 做什么 | 用户收益与边界 |
| --- | --- | --- |
| E1 | 底部独立面板：上方紧凑播放栏，下方标尺、播放头、动效轨与批注轨 | 从播放器进度条升级为可读的审阅结构；配色沿用产品主题，信息层次靠布局和选中状态表达。 |
| E2 | 左侧时间码点击编辑；输入前确认暂停，Enter 提交，Escape 取消 | 消除播放时输入被时钟覆盖的问题，保留精确秒数定位。已知 FPS 才展示帧信息，未知时使用 0.1 秒步进。 |
| E3 | 真实单源动效片段轨，显示当前文件和总时长；点击 / 拖动定位，播放头跨轨道对齐 | 当前输入是一份 GSAP Motion HTML，没有通用可编辑片段模型，因此首版展示一个完整源片段。不伪造分镜、音频波形、图层或剪辑手柄。可靠通用场景声明留到下一层。 |
| E4 | 当前来源的既有时间批注显示为可点击标记，重合时聚合 | 从时间线定位既有反馈，并复用现有评论面板与加入对话操作。旧来源保留在评论列表和原截图中，不冒充当前内容标记；不承诺历史工程恢复。 |
| E5 | “标注此刻”继续使用现有点选 / 区域标注，提交仍走已有评论与聊天 | 本次不新增第二套对话或反馈协议；暂停、锁定、截图失败保稿等保护继续有效。 |
| E6 | 时间线与画布预留高度共享一个尺寸值；窄预览压缩标签，核心操作可用 | 适配聊天展开 / 收起与小窗口，避免面板遮住画面或控件溢出。 |

首版不含直接改字 / 改色 / 拖位置、不含多轨剪辑、关键帧、曲线和区间批注。这些需要稳定的编辑对象、写入语义和撤销持久化，应另做方案。MP4 与非 canonical Motion HTML 保持原入口。

## 技术方案

- `MotionPlaybackControls` 继续消费现有已确认的 `MotionPlayerState`，只改布局、定位输入与批注标记交互，不另建播放时钟。
- 控件使用 CSS Module；底部高度通过文件预览容器上的 CSS 自定义属性同时供画布裁切区和面板消费。无手写第二套绝对高度。
- 片段轨复用原生 range 提供键盘与读屏定位，透明输入覆盖自绘标尺 / 轨道，刻度根据实际时长生成。播放头只由已确认状态更新；不将鼠标位置冒充实际时钟。
- 控件接收经过过滤的轻量批注摘要（ID、参考时间、显示序号、文字），不依赖 FileViewer 私有评论实现；点击回调复用同一现有评论打开流程。仅当前文件、当前来源、有效时长范围内的反馈进入标记轨。普通播放 / 定位在标注锁定时禁用；浏览已有评论仍可点击其他 marker，先走原草稿防丢入口，再解锁 → 跳时 → 锁定。绘制、标注初始化、截图 / 保存和切换执行中禁用 marker，防止并发改时刻。
- **画面区域**：面板从实际画布高度中占位，clip 的剩余区域就是可见画面。初版适配中实际发现：作者的 transform 祖先会改变 runtime fixed stage 的包含块，导致重复居中偏移。最终实现从源声明读取输出宽高，让 Motion iframe 保持作品逻辑视口，再由宿主按实际剩余区域统一 contain / 居中。元素 overlay 与宿主使用同一 scale 和 offset；尺寸无法解析时回退原缩放 shell。manual edit 与非 Motion 保持原路径，不改源文件和 runtime fit。该修正经过独立窄范围技术复核通过；验收覆盖 desktop、tablet / mobile preset、窄栏下的完整画面及实际标注坐标。
- 秒数编辑先等待暂停确认再进入输入状态，输入期间不接受时钟写入；取消不能触发 blur 提交；切源通过组件 key / 状态边界清除旧草稿。命令失败保留实际时间并提示。
- 不改 contracts、数据库、daemon HTTP 和 CLI。本轮是既有播放与评论能力的 UI 组织，持久能力仍走已实现的同一评论 API / `od comment`，不存在新增 UI 专属持久能力。

## 验收与效果口径

1. 真实 ECOTREE 动效中播放 / 暂停、拖动 / 点击定位、逐帧与时间输入可用；输入开始后画面暂停，Enter 生效、Escape 保持原位置。
2. 时间线显示真实总时长和单源片段，播放头与已确认时间一致；当前来源批注能定位并打开原评论；旧来源不混入当前轨道。
3. 在时间线进入标注，保存截图与文字，再加入现有对话；回读证据含时间、来源和图片。若调用模型验证，用独立副本与新会话，不修改此前对照实验的产物。
4. 聊天展开 / 收起及窄面板无遮挡；连接中、错误、未知 FPS、标注锁定仍可辨识。
5. 聚焦组件与受影响集成边界测试；运行仓库 guard / typecheck。浏览器检查关键用户路径并保存真实截图，不以测试通过代替界面验收。

本轮能证明界面和反馈链路是否可用，不能直接证明首次修改成功率、轮次或人工准备耗时改善。已有模型对照实验不重跑、不混入本轮新样本。后续对比人工成本时测“定位目标 → 准备并提交修改要求”的耗时与误定位次数。

## 本地实现与验收结果

已在当前分支实现真实产品内的首版，不使用前一轮独立 HTML 草图替代产品验收。

- 新控件包含时间码编辑、播放 / 暂停 / 重播、已知 FPS 逐帧、标尺与播放头、真实文件片段和批注轨。秒数编辑一律等待实际暂停确认，避免快速播放后立即编辑的竞态；Enter 提交一次，Escape 取消不定位。
- marker 复用侧栏同一评论入口，保留草稿防丢、文档核验、原截图与权限；聚合相邻标记可选择具体评论。时间轨和 marker 的命中区域分开。
- Motion 宿主画布保留输出逻辑视口，使用真实画布尺寸统一适配与居中；原 ECOTREE 作者 transform 祖先造成的重复偏移已在宿主层避免。未修改原实验产物与共享播放器 runtime。
- 新增文案覆盖仓库当前 19 个 locale。无新增 HTTP、DB 或 CLI 语义。

### 实际浏览器

独立验收项目 `motion-editor-20261026`，会话 `9534df1b-777f-4ca5-9739-7d22400e8894`。初始 HTML 与此前 ECOTREE 新流程终稿的 SHA-256 一致（`d92bcfd6…552ed0d`）；此前对照实验的项目和产物未变。

已观察到：

1. 点击播放中的时间码后暂停，再输入 6.8 秒定位到第 205/360 帧；点“下一帧”变为 6.833 秒、第 206 帧，再播放可继续推进。
2. 从播放状态点击 6.8 秒的批注 marker，回到原时间并打开原修改意见；保存意见后 marker 出现在对应时间位置。
3. 评论侧栏展开 / 关闭后，选中标题的框仍贴合目标。iframe 内根节点为完整 1920×1080，`top=0`，避免此前重复居中偏移。当前源码渲染确认标题 72px、颜色 `rgb(40, 50, 44)`。
4. 最终代码中实测时间输入 Escape：实际暂停于 0.466 秒，输入 3.5 后取消，仍停在 0.466 秒。
5. 检查桌面、平板 / 移动端 preset 和 349px 窄预览，作品完整显示，核心控件可用。未覆盖任意极端窗口尺寸或所有操作系统。

### 一次真实模型修改

从 6.8 秒标题批注点击“发送到聊天”，现有产品队列自动启动模型修改，并非只把文字放进输入框。该真实链路已完成：

- 实际诊断模型：`amr / deepseek-v4.1-flash`，沿用当前 UI 所选模型；与此前 A/B 的 `gpt-6.1-sol` 配置不同。
- Run：`f8830108-3296-47b2-9c5b-428551292973`，终态 `succeeded`。创建至终态 68,074ms，UI 约显示 68–69 秒。
- 请求：“标题字号小一档，保留当前换行和颜色。”
- 真实源码差异只有 `#scene-3 h2 { font-size: 80px; }` → `72px` 一条规则；其他源码字节保持一致。浏览器确认该标题实际渲染为 72px。
- 这是一个端到端可用性单例，不是新旧流程效果对照，不能据此声明首次成功率、轮次或效率提升；未独立证实模型消费了截图像素。

修改完成后另存了一条当前来源批注，供用户继续试用；未再次启动模型。

### 素材条画面预览补充（2026-10-26）

按实际素材条宽度显示 2–6 张真实画面，每张取对应时间区间的中点。12 秒 ECOTREE 在当前全宽预览中显示 1、3、5、7、9、11 秒的 6 张画面；窄栏显示 2、6、10 秒的 3 张画面。缩略图与现有透明 range 叠放，点击 / 拖动仍按整条时间轴定位，不阻挡下方批注标记。

本版使用独立、静音、暂停锁定的沙箱预览呈现原生画面，保留源文件的 CSS、SVG 和相对资源，不经过截图桥。每张画面拥有独立 transport，只有当前文档完成定位与锁定确认后才显示；重新加载或来源变化会隐藏旧画面并重新确认。总数上限为 6，切换离开当前预览或流式生成时卸载，尚未针对大型复杂作品量化内存与加载开销。素材条高度增加 24px，画布预留使用同一尺寸常量；主 iframe 首次测量前也使用作品逻辑尺寸，避免作者 fit 在零尺寸视口下初始化。

最终代码实际验收：点击素材条定位到 3.412 秒，拖动定位到 6.704 秒；打开已有批注回到 6.8 秒，关闭批注后播放与定位恢复。聊天收起使缩略图从 3 张增至 6 张后，主播放器仍保持暂停在 6.8 秒。主预览根节点实际为完整 1920×1080。未修改源作品或再次调用模型。

定向组件与集成测试 15/15 通过，覆盖来源隔离、定位 / 锁定 ACK、重载重新确认和来源变更卸载；Web TypeScript 与仓库 guard 通过。以上是界面可用性验收，不是首次修改成功率或耗时改善的对照证据。MP4 等其他素材入口未在本次扩展。

增量独立技术复核通过，无剩余阻塞。6 张是并发文档数上限，尚不是位图缓存；单张超时显示占位，可通过现有重载或切换来源恢复，不作无限重试。
