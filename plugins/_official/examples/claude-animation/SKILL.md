# Hand-painted character animation

Use the bundled `claude-animation` skill supplied by this preset's context.
It owns the animation guide, character references, starter HTML and rendering
workflow. Author a scene for the user's story, then dispatch the final MP4
through the Open Design media renderer. Keep output at five seconds, 16:9,
24 fps and silent. Do not deliver an HTML preview instead of the video.
